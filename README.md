# 🎮 Adam Zombie Game - Selettore di Giochi

## Benvenuti! 👋

Questo progetto contiene due giochi arcade sviluppati da **Not Exist**:

- **Alien Destroyer** 🛸 - Distruggi gli alien invasori nello spazio
- **Zombie Survival** 🧟 - Sopravvivi all'apocalisse zombie

---

## 🚀 Come Giocare

### 1. Apri il Selettore di Giochi
Apri il file `index.html` nel tuo browser preferito:

```
file:///C:/Users/pietr/OneDrive/Desktop/Prova/zombie-game-new/index.html
```

Oppure vai su GitHub: https://github.com/0NotExist0/adamgame

### 2. Scegli il Tuo Gioco! 🎯

Sul sito vedrai due carte interattive:

| Gioco | Descrizione | Features |
|-------|-------------|----------|
| 👾 **Alien Destroyer** | Nave spaziale contro alien invasori | Sparo automatico, sistema livelli, controllo mouse |
| 🧟 **Zombie Survival** | Sopravvivenza all'apocalisse zombie | Sparo manuale, multiplayer, controllo completo |

### 3. Inizia a Giocare! ⚔️

Clicca su **"Gioca Ora"** nella carta del gioco preferito:
- Il gioco si caricherà automaticamente
- Puoi giocare con il mouse o i controlli touch
- Chiudi il gioco con il pulsante **❌ Chiudi Gioco** quando vuoi tornare al selettore

## 🎮 Controlli Gioco

### Alien Destroyer 👾
- **Mouse**: Muovi la nave (segue il cursore orizzontalmente)
- **Click**: Spara manualmente (opzionale - sparotomatico attivo)
- **Obiettivo**: Distruggi gli alien, guadagnare punti e aumentare di livello

### Zombie Survival 🧟
- **WASD/Frecce**: Muovi il giocatore
- **Clic/Tasto**: Spara sul nemico
- **R Reload**: Ricarica le munizioni
- **Obiettivo**: Sopravvivi al più a lungo possibile!
